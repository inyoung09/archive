GitHub 토큰 만들기

메모를 저장하려면 ‘토큰’(일종의 열쇠)이 한 번 필요해요. GitHub 화면은 영어라서 버튼 이름을 굵은 글씨로 적었어요.

  1. github.com 에 로그인 → 오른쪽 위 프로필 사진 → Settings
  2. 왼쪽 메뉴 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Token name: archive-memo / Expiration: 1년 (Custom 또는 1 year 이 보이면 그것, 없으면 가장 긴 기간) / Resource owner: inyoung09
  5. Repository access → Only select repositories → inyoung09/archive 선택
  6. Permissions → Repository permissions → Contents → Read and write (Metadata는 자동으로 Read-only 예요)
  7. 맨 아래 Generate token → 나오는 github_pat_… 값을 복사하세요. 이 화면을 벗어나면 다시 볼 수 없어요!
  8. 아카이브 메모 페이지 → ⚙ 설정 → 붙여넣기 → 저장 → 연결 확인 (‘연결됐어요 ✓’ 가 나오면 끝)
알아 두세요
· 기간이 지나 토큰이 만료되면 같은 방법으로 새로 만들고, 설정에서 다시 붙여넣으면 돼요.
· 토큰은 이 브라우저에만 저장돼요. 다른 사람에게 보내거나 어디에도 올리지 마세요.
